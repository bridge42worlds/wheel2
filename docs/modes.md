# Режимы: что делает установка в каждом

Все режимы «Колеса-2» словами основного экрана: что происходит, на что смотреть, типичные цифры
(XIAO ESP32-S3, 256 бит, 240 МГц, предел 73 °C). Режим опыта складывается из независимых частей — это и
есть параметры опыта в эксперименте: **вращение** (скорость, отступ от невесомости), **поле**,
**излучение / поглощение**, **совместная работа**, **поглощение**, **шум**. Как из них строится
эксперимент — [program.md](program.md).

Установка: **колесо 1** и **колесо 2** по шесть агентов (на колесе — подгруппы а–з, каждая на опыте
считает своей группой), **статика** между колёсами (акселерометр, телефон), **агенты катушек** и
**агент моторов**. Роли: ▶ генерация, ▼ поглощение, ◆ статика, ⚙ моторы / катушка.

## Состояния установки

| состояние | что делают генераторы | статика | когда |
|---|---|---|---|
| ⏸ **стоит** | не считают и остывают: 80 МГц, светодиод выкл | меряет | между опытами, эталон шума, опыт «все стоят» |
| ▶ **идёт опыт** | каждая подгруппа — по режиму опыта | меряет | опыт |
| ⏸ **отдых** | стоят на 80 МГц, пока температура не установится | меряет | перед опытом, если отдых задан |
| ≋ **тушение с пульта** | только рассеивают свой шум (пустышка, фон 50 кадров/с) — ни одного простого | меряет | контроль «радио без чисел» |

## Излучение / поглощение: роль колеса

В окне эксперимента — сетка 3 × 3: строка — колесо 1, столбец — колесо 2 (стоит · генерирует ·
поглощает); ▼▼, ▼⏸, ⏸▼ недоступны — поглощать нечего.

| вариант | слово на экране | на что смотреть |
|---|---|---|
| ▶ ▶ | оба генерируют — каждое колесо своей группой (или одной на двоих: «оба колеса одной группой») | влияние соседа |
| ▶ ⏸ / ⏸ ▶ | только К1 / только К2 | эталон темпа одного колеса, сравнение колёс |
| ▶ ▼ / ▼ ▶ | К2 поглощает / К1 поглощает простые другого | основной опыт «излучение — поглощение», симметрия |
| ⏸ ⏸ | только статика: никто не считает, вращение и поле — как в опыте | что вращение и поле делают с датчиками сами |

## Поглощение

Своя карточка эксперимента, две строки, перебирается каждое сочетание. Подробно —
[scatter.md](scatter.md).

| кто чьё | что |
|---|---|
| все со всеми | каждый поглотитель берёт простые всех генераторов |
| пары 1:1 | у каждого поглотителя свой генератор по номерам; генераторы без пары — контроль внутри опыта |
| все — одного | все поглощают простые первого генератора; остальные — без поглощения |
| каждое — одному | генераторы поделены между поглотителями: каждое простое поглощается ровно один раз |
| половина колеса | первую половину генераторов поглощают все, вторую — никто |

| как | что |
|---|---|
| смешать целиком | каждый смешивает всё простое со своим шумом и выпускает кадр |
| по кускам | каждый смешивает свой кусок числа: ни один кадр не несёт число целиком |
| эстафетой | по цепочке, последний выпускает один кадр |
| пустышка | тот же трафик, вместо числа шум — отделяет действие числа от действия радио |
| только слушают | принимают простые, в эфир ничего — контроль без трафика |

По кускам и эстафетой — всегда «все со всеми». На пульте и в живой схеме есть ещё **фон** — свой шум
поглотителей с заданной частотой.

## Совместная работа: как генераторы ищут простые

| способ | как работает | простых/с | на что смотреть |
|---|---|---|---|
| **эгоистичный** | каждый сам набирает шум, складывает число, отсеивает, проверяет | ~26 на агента, два ядра ~45 | выход против теории, отсев |
| **групповой · каскад** | числа из кусочков шума всех агентов подгруппы, проверяют все сразу, каждый свои | 4 агента ~85–90, 6 — ~100–118 | доля кругов из кусочков всех (когерентность), тепло |
| групповой · эстафета | число из шума всех, проверяет один, ход по кругу | ~37 на группу, платы прохладнее | ходы поровну, «молчащие» |
| групповой · одно число на всех | одно число из шума всех, проверяют все (базы поделены), ответ по согласию | ~8–11 на группу | согласие ответов, циклы без сбоев; опыт лучше 60 с |
| групповой · одинаковые числа | все считают одно число | — | появится с прошивкой |

Подробно — [group_protocol.md](group_protocol.md).

## Шум: откуда берётся число

| значок | шум | быстрота |
|---|---|---|
| ⚄ | ГСЧ чипа — аппаратный генератор с шумом приёмника Wi-Fi | ~45 тыс. слов/с — основной |
| Σ | все доступные: ГСЧ + CSI с пульса + АЦП + дрожание RC через SHA-256 | как самый медленный |
| ≋ | CSI с пульса — состояние радиоканала по кадрам пульса соседей | медленно |
| ↯ | CSI с пинга роутера — то же по ответам роутера на пинг | медленно, осторожно |
| ⏚ | АЦП D0 — свободный вход D0 | медленно |
| ⧖ | дрожание RC — внутренний генератор против кварца | медленно |
| ↺ | обратный шум — кадры поглотителей другого колеса, петля через эфир | только когда другое колесо поглощает |
| ↕ 🧲 | акселерометр, магнитометр обода (у агентов с датчиком) | очень медленно |

**Шум — смесь источников.** В окне эксперимента шум собирается значками; «Σ все» отмечает четыре
основных (ГСЧ, CSI, АЦП, RC). Отмеченные вместе — одна смесь. **Как перебирать** (можно несколько):

| перебор | варианты | 4 источника | 6 (+ акс., магн.) |
|---|---|---|---|
| все вместе | все отмеченные — одна смесь | 1 | 1 |
| по одному (включение) | каждый источник отдельно — что даёт каждый | 4 | 6 |
| без одного (исключение) | смесь без каждого по очереди — чего без него не хватает | 4 | 6 |
| все три | смесь, без каждого, каждый отдельно | 9 | 13 |

Без хеша (`raw`) видна физика источника (у АЦП 54–59 % единиц), с фон Нейманом снят перекос. Как шумы
берутся, засчитываются и смешиваются — [randomness.md](randomness.md).

## Поле катушек

Каждая катушка — выкл, + или −: сетка 3 × 3 (строка — катушка колеса 1, столбец — колеса 2), 9 вариантов;
быстрый выбор «выкл · одного знака · разных знаков · одна катушка · все 9».

| вариант | слово на экране |
|---|---|
| выкл выкл | обе выкл |
| + + / − − | одного знака |
| + − / − + | разных знаков |
| + выкл, − выкл / выкл +, выкл − | только К1 / только К2 |

«+» и «−» — направление тока (OUT1 → OUT2 или обратно); поле внутри трубы 1,20–1,26 мТл при 0,85–0,98 А (замер, [coil_test.md](coil_test.md)). Поле
включают агенты катушек в начале опыта; на отдыхе, на паузе, в конце программы и по «■ Всё стоп» — выкл.
Вручную — «выкл / + / −» под колесом на схеме. Схема — [wiring.md](wiring.md).

## Вращение колёс

Каждое колесо — стоит (■), вперёд (⟳ — по часовой, если смотреть на вал спереди) или назад (⟲): сетка
3 × 3, 9 вариантов.

| вариант | слово на экране |
|---|---|
| ■■ | стоят — моторы выключены |
| ⟳⟳ / ⟲⟲ | вместе / вместе назад |
| ⟳⟲ / ⟲⟳ | навстречу |
| ⟳■ ⟲■ / ■⟳ ■⟲ | только К1 / только К2 |

**Скорость:** обороты (об/мин, ПИ по датчику обода), ШИМ (доля питания) или **невесомость** — обороты,
при которых наверху колеса k = ω²r/g = 1 (r по датчику обода; при 450 мм — 44,6 об/мин). **Отступ от
невесомости** — ступени около расчётной: 0, ±1, ±2 шага, шаг по умолчанию 3 % оборотов; k меняется
вдвое сильнее (+3 % — k ≈ 1,06). Разгон и смена направления плавные, через остановку и паузу 1 с;
сторож — нет команды 5 с, моторы встают. Окно «⟳ моторы вручную…» крутит колёса вне эксперимента.
Подробно — [sensors.md](sensors.md).

## Телеметрия: сколько агенты говорят

| режим | генераторы | статика | что видно |
|---|---|---|---|
| **обычная** | пакет раз в секунду | шлёт отсчёты | всё в реальном времени |
| **редкая** | в 10 раз реже | шлёт отсчёты | итоги, без подробностей во времени |
| **молчание** | ничего, кроме подтверждений команд | шлёт отсчёты | только статика; итоги — после опыта |

Молчание — чтобы свои кадры Wi-Fi не влияли на статику; в эксперименте — «молчание телеметрии во время
опыта» (⑥ тонкости, по умолчанию вкл), действует только на измерение. Молчат и датчики шины: обороты
обода и поле катушки на измерении не видны, регулятор моторов держит последний ШИМ (в «невесомости» — и
последний радиус обода), а обороты и поле в записи
опыта берутся из проверки (10 с до молчания) и итогов (после). «Wi-Fi выкл на опыте» (с опытом на агенте)
убирает радио целиком — только у эгоистичного счёта без поглощения и без шума из эфира.

## Смежное

* **Статика** — неподвижный датчик меряет 500 раз в секунду, сервер сравнивает каждые 10 с с эталоном
  шума: ✓ продолжать · ⚠ проверить · ↻ повторить — [static_watch.md](static_watch.md).
* **Тепло** — регулятор, отдых перед опытом, спринт, рейтинг агентов — [thermal.md](thermal.md).
