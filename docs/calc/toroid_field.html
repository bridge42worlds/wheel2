Поле тороида

Кольцевая катушка без сердечника с неравномерной толщиной трубки и неравномерной намоткой. Поле считается по закону Био–Савара для каждого витка прямо в браузере. Главная величина на картах — отклонение от идеального тора, у которого внутри B = μ₀NI/(2πr).

Сечение трубки

Смотрим вдоль поля: слева ось кольца, справа наружная сторона. Стрелки показывают поперечную часть поля (B_r, B_z), их длина условная. Именно эта часть наклоняет силовые линии.

Гармоники вдоль кольца

по вертикали амплитуда, % · по горизонтали число волн m
толщина — первый столбик плотность — второй поле на оси — третий

Медленные волны (малый номер) доходят до оси трубки почти целиком, быстрые гаснут к центру. Для плотности до оси доходит доля около ka·K₁(ka), где k = m/R, m — номер гармоники.

Как считается

Каждый из N витков — круговая петля в своей меридиональной плоскости, с радиусом трубки a(φ) в этом месте. Её поле считается точно, через эллиптические интегралы. Петли дальше 10a от точки заменяются диполем, это даёт ошибку меньше 10⁻⁵ от B₀. Углы витков задаёт профиль плотности n(φ), полное число витков всегда N. Ход провода вдоль кольца моделируется током I, размазанным по поверхности трубки шестнадцатью горизонтальными кольцами.

Проверка. Идеальный тор с теми же R, a и N даёт внутри b = 1 с точностью 2·10⁻⁵, снаружи поле меньше 3·10⁻⁵ B₀. Одна синусоида плотности ±10% с шестью волнами по кольцу даёт на оси трубки ±7,81%; аналитическая оценка для соленоида ka·K₁(ka) даёт ±7,8%.

Числа в сводке не учитывают пристеночный слой толщиной полтора шага намотки. Там поле рябит от отдельных витков, и эта рябь гаснет за один шаг.

Обозначения: B₀ = μ₀NI/(2πR) — поле идеального тора на оси трубки; b = B_φ·2πr/(μ₀NI) — продольное поле в долях идеального в той же точке. У идеального тора b = 1 во всём объёме трубки, хотя само поле падает от внутренней стенки к внешней как 1/r.
