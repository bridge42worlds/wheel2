Режимы: что делает установка в каждом

Все режимы «Колеса-2» словами основного экрана: что происходит, на что смотреть, типичные цифры (XIAO ESP32-S3, 256 бит, 240 МГц, предел 73 °C). Режим опыта складывается из независимых частей — это и есть параметры опыта в эксперименте: вращение (скорость, отступ от невесомости), поле, излучение / поглощение, совместная работа, поглощение, шум. Как из них строится эксперимент — program.md.

Установка: колесо 1 и колесо 2 по шесть агентов (на колесе — подгруппы а–з, каждая на опыте считает своей группой), статика между колёсами (акселерометр, телефон), агенты катушек и агент моторов. Роли: ▶ генерация, ▼ поглощение, ◆ статика, ⚙ моторы / катушка.

Излучение / поглощение: роль колеса#

В окне эксперимента — сетка 3 × 3: строка — колесо 1, столбец — колесо 2 (стоит · генерирует · поглощает); ▼▼, ▼⏸, ⏸▼ недоступны — поглощать нечего.

Поглощение#

Своя карточка эксперимента, две строки, перебирается каждое сочетание. Подробно — scatter.md.

кто чьёчто
все со всемикаждый поглотитель берёт простые всех генераторов
пары 1:1у каждого поглотителя свой генератор по номерам; генераторы без пары — контроль внутри опыта
все — одноговсе поглощают простые первого генератора; остальные — без поглощения
каждое — одномугенераторы поделены между поглотителями: каждое простое поглощается ровно один раз
половина колесапервую половину генераторов поглощают все, вторую — никто
какчто
смешать целикомкаждый смешивает всё простое со своим шумом и выпускает кадр
по кускамкаждый смешивает свой кусок числа: ни один кадр не несёт число целиком
эстафетойпо цепочке, последний выпускает один кадр
пустышкатот же трафик, вместо числа шум — отделяет действие числа от действия радио
только слушаютпринимают простые, в эфир ничего — контроль без трафика

По кускам и эстафетой — всегда «все со всеми». На пульте и в живой схеме есть ещё фон — свой шум поглотителей с заданной частотой.

◈ Своё рассеяние (ss) — без поглотителей: генератор сам выпускает каждое своё простое, смешав со своим шумом (ядро счёта ищет, ядро связи рассеивает); пустышка — тот же трафик без числа. Слой окна эксперимента: нет / сами рассеивают / пустышка. Подробно — scatter.md.

Шум: откуда берётся число#

значокшумбыстрота
⚄ГСЧ чипа — аппаратный генератор с шумом приёмника Wi-Fi~45 тыс. слов/с — основной
Σвсе доступные: ГСЧ + CSI с пульса + АЦП + дрожание RC через SHA-256как самый медленный
≋CSI с пульса — состояние радиоканала по кадрам пульса соседеймедленно
↯CSI с пинга роутера — то же по ответам роутера на пингмедленно, осторожно
⏚АЦП D0 — свободный вход D0медленно
⧖дрожание RC — внутренний генератор против кварцамедленно
↺обратный шум — кадры поглотителей другого колеса, петля через эфиртолько когда другое колесо поглощает
↕ 🧲акселерометр, магнитометр обода (у агентов с датчиком)очень медленно

Шум — смесь источников. В окне эксперимента шум собирается значками; «Σ все» отмечает четыре основных (ГСЧ, CSI, АЦП, RC). Отмеченные вместе — одна смесь. Как перебирать (можно несколько):

переборварианты4 источника6 (+ акс., магн.)
все вместевсе отмеченные — одна смесь11
по одному (включение)каждый источник отдельно — что даёт каждый46
без одного (исключение)смесь без каждого по очереди — чего без него не хватает46
все трисмесь, без каждого, каждый отдельно913

Без хеша (raw) видна физика источника (у АЦП 54–59 % единиц), с фон Нейманом снят перекос. Как шумы берутся, засчитываются и смешиваются — randomness.md.

Поле катушек#

Каждая катушка — выкл, + или −: сетка 3 × 3 (строка — катушка колеса 1, столбец — колеса 2), 9 вариантов; быстрый выбор «выкл · одного знака · разных знаков · одна катушка · все 9».

вариантслово на экране
выкл выклобе выкл
+ + / − −одного знака
+ − / − +разных знаков
+ выкл, − выкл / выкл +, выкл −только К1 / только К2

«+» и «−» — направление тока (OUT1 → OUT2 или обратно); поле внутри трубы 1,20–1,26 мТл при 0,85–0,98 А (замер, coil_test.md). Поле включают агенты катушек в начале опыта; на отдыхе, на паузе, в конце программы и по «■ Всё стоп» — выкл. Вручную — «выкл / + / −» под колесом на схеме. Схема — wiring.md.

∿ Род поля — отдельный слой: постоянное или переменное — ∿ синус или ⊓ мягкий меандр с частотой 0,1–50 Гц (свою частоту можно добавить; не кратную 10 Гц — иначе магнитометр обода поле почти не увидит); контроль «= 70 % · ШИМ» — постоянное слабее, мост переключается, поле не меняется; ⟳ с вращением — синус частоты оборотов × k, максимум поля у верха агента с акселерометром (по его метке верха). У переменного «+» и «−» — фаза 0 и 180°: «+ +» — катушки в одной фазе, «+ −» — в противофазе. Амплитуда растёт и спадает плавно, за 3 периода (1–5 с). Где катушки выкл, род поля не перебирается. Вручную — кнопка «∿» под колесом (род по кругу). Подробно — sensors.md.

Вращение колёс#

Каждое колесо — стоит (■), вперёд (⟳ — по часовой, если смотреть на вал спереди) или назад (⟲): сетка 3 × 3, 9 вариантов.

вариантслово на экране
■■стоят — моторы выключены
⟳⟳ / ⟲⟲вместе / вместе назад
⟳⟲ / ⟲⟳навстречу
⟳■ ⟲■ / ■⟳ ■⟲только К1 / только К2

Скорость: обороты (об/мин, ПИ по датчику обода), ШИМ (доля питания) или невесомость — обороты, при которых наверху колеса k = ω²r/g = 1 (r по датчику обода; при 450 мм — 44,6 об/мин). Отступ от невесомости — ступени около расчётной: 0, ±1, ±2 шага, шаг по умолчанию 3 % оборотов; k меняется вдвое сильнее (+3 % — k ≈ 1,06). Разгон и смена направления плавные, через остановку и паузу 1 с; сторож — нет команды 5 с, моторы встают. Окно «⟳ моторы вручную…» крутит колёса вне эксперимента. Подробно — sensors.md.

Телеметрия: сколько агенты говорят#

режимгенераторыстатикачто видно
обычнаяпакет раз в секундушлёт отсчётывсё в реальном времени
редкаяв 10 раз режешлёт отсчётыитоги, без подробностей во времени
молчаниеничего, кроме подтверждений командшлёт отсчётытолько статика; итоги — после опыта

Молчание — чтобы свои кадры Wi-Fi не влияли на статику; в эксперименте — «молчание телеметрии во время опыта» (⑥ тонкости, по умолчанию вкл), действует только на измерение. Молчат и датчики шины: обороты обода и поле катушки на измерении не видны, регулятор моторов держит последний ШИМ (в «невесомости» — и последний радиус обода), а обороты и поле в записи опыта берутся из проверки (10 с до молчания) и итогов (после). «Wi-Fi выкл на опыте» (с опытом на агенте) убирает радио целиком — только у эгоистичного счёта без поглощения и без шума из эфира.

Смежное#

  • Статика — неподвижный датчик меряет 500 раз в секунду, сервер сравнивает каждые 10 с с эталоном шума: ✓ продолжать · ⚠ проверить · ↻ повторить — static_watch.md.
  • Тепло — регулятор, отдых перед опытом, спринт, рейтинг агентов — thermal.md.
