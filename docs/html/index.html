Колесо-2 — документация

Агенты — платы XIAO ESP32-S3 с общей прошивкой prime_lab: генерируют простые числа (каждый сам или сообща), рассеивают их (сет B), меряют ускорение (роль S). Сервер на ПК собирает телеметрию, раздаёт настройки и прошивки, ведёт сессии, программы и журнал опытов.

Живые страницы

  • Главная панель — агенты, управление, сессии, итоги, графики, журнал опытов, прошивка по Wi-Fi; у каждого параметра значок ⓘ.
  • Живая схема — протокол по шагам, замедленно: шум, кандидат, отсев, Миллер — Рабин, мастер и эстафета, кусочки, рассеяние, петля; характерные времена «модель / на платах».
  • Второй экран — статические акселерометры: спектр, эталон шума, вывод.

Режимы на живой схеме

  • сообща: мастер, эстафета, запас
  • эстафета сета A: проверяет один, ход по кругу
  • каскад сета A: проверяют все, шум от всех ко всем
  • сообща + рассеяние
  • россыпь

  • тишина и фон

  • сообща на медленном шуме (CSI)

Документы

Режимы

Все режимы установки в одном месте: стоп, пуск, тушение, отдых; генерация (каждый сам, два ядра, все на одном числе, эстафета, каскад); шум; поглощение (сет B); статические; телеметрия; программа.

Концепт: пульт и наблюдение

Два экрана: пульт (36 агентов, группы и режимы, опыт, программа «план — факт», журнал) и наблюдение (статика и простые в реальном времени). Черновик для обсуждения.

Как всё работает

Система целиком: агент и его ядра, источники шума, поиск простого, сообща, предел температуры, параметры, сессии, страницы, телеметрия, прошивка по Wi-Fi, замеры, инструменты.

Сообща: протокол группы

Все на одном числе (третья версия): число с итогом, базы по кругу, запас и кусочки, сбои, когерентность, согласие, результаты на 1–4 платах. Эстафета и каскад: число из шума всех, проверяет один или все, оценка по модели.

Рассеяние: сет B

Как простое попадает к сету B, режимы (каждый, россыпь, эстафета, тишина), пустышка, фон, функции, окна по местам, петля через эфир, проверка на четырёх платах.

Откуда берётся случайность

ГСЧ чипа и шум радио, CSI, АЦП, дрожание RC: как берём, сколько засчитываем, как смешиваем, скорость по источникам и длинам.

Температура агентов

Предел 70 °C: регулятор доли работы, замеры нагрева и остывания, откуда тепло, частота, отдых по очереди, спринт после отдыха, отдых между режимами, рейтинг агентов по истории ошибок.

Программа эксперимента

Шаги, контроль, случайный порядок, эталон шума, аномалии и их проверка парами, испорченные шаги.

Статические акселерометры

Роль S: что меряет агент, что считает сервер, эталон шума, линии, полосы, толчки, вывод «продолжать / повторить / проверить».

Датчики

Колесо (обороты и невесомость), магнитное поле, статический акселерометр; подключение и пакеты.

English#

An experimental rig that looks for information anomalies in the generation of prime numbers. Seeed XIAO ESP32-S3 boards ("agents") sit on two rotating wheels (radius 450 mm), each wheel wound with a coil. The agents continuously search for primes in physical noise — the chip's hardware random generator, the Wi-Fi radio channel (CSI), ADC noise on a floating pin, jitter of the internal RC oscillator — either each on its own or cooperatively over ESP-NOW. Static accelerometers stand between the wheels. The question is whether how and where the numbers are born — selfish or group generation, absorption of the primes by the other wheel, rotation, the coil field — changes the statistics of the numbers themselves or the readings of the static sensors.

Every mode is compared with control steps under a criterion named before the run (Student's t with a Bonferroni correction over pre-registered metrics, randomised order, rest to a stable chip temperature between steps, temperature and work fraction as covariates). No anomaly has been found so far: null programs are clean, and 511,000 primes in the run of 2026-10-07 are within chance.

Web pages of the server (http://<server>:8090/…): /plan — the experiment board (layers → matrix of steps → program, live drawing of the rig, step timer and totals), /report — per-step report with CSV export, /pult and /watch — console and live results, /flow — slowed-down animated model of the protocols, /docs/ — documentation in HTML.

Quick start

  1. Copy secrets.example/ to secrets/ and put your Wi-Fi network into secrets/wifi.ini (secrets/ is never committed; the OTA signing key is created there on the first build).
  2. Build and flash the first time over USB: tools/build.sh prime_lab COM5 (Git Bash; set the path to arduino-cli in CLI= at the top of the script; board esp32:esp32:XIAO_ESP32S3, ESP32 core 3.3.7). Later updates go over Wi-Fi: tools/build.sh prime_lab, then python tools/ota.py all.
  3. Start the server: python server/monitor.py (on Windows tools/monitor.cmd) and open http://localhost:8090/plan. Agents find the server by its UDP beacon (ports: 5005 telemetry, 5006 beacon, 5007 commands, HTTP 8090).
  4. No boards at hand? Simulated agents: python server/monitor.py --http 8092 --udp 5016 --data data/test/gen --no-beacon and python tools/sim_gen.py 4 --port 5016, then http://localhost:8092/plan.

Wiring notes. Leave pin D0 unconnected — it is the ADC noise source. Rim sensors go on I²C (D4 SDA, D5 SCL). When agents are powered from a common 5 V bus, put a Schottky diode (1N5819 / SS34) in series with +5 V of every board (anode to the bus); the XIAO's 5V pin is tied to USB VBUS, and a board plugged into a computer while on the bus would otherwise connect two 5 V sources.

How everything works, all parameters, measurements — docs/en/how_it_works.md. The other documents (noise sources, group protocol, scattering, thermal behaviour, programs) are in Russian. Licence: MIT (LICENSE).

Русский#

Экспериментальная установка: платы Seeed XIAO ESP32-S3 («агенты») стоят на двух вращающихся колёсах с катушками и непрерывно ищут простые числа из физического шума — аппаратного генератора чипа, радиоканала Wi-Fi (CSI), шума АЦП, дрожания внутреннего генератора. Между колёсами стоят неподвижные акселерометры. Вопрос опыта — влияет ли то, как и где рождаются числа (каждый агент сам или сообща, поглощение простых другим колесом, вращение, поле катушек), на статистику самих чисел или на показания неподвижных датчиков. Каждый режим сравнивается с контрольным шагом по заранее названному критерию (Стьюдент с поправкой Бонферрони). Пока аномалий не найдено: нулевые программы чисты, 511 тыс. простых в прогоне 07.10.2026 — в пределах случайного.

Лицензия — MIT (LICENSE).

Секреты (secrets/wifi.ini — сеть, secrets/ota.key — ключ подписи прошивок) в git не попадают: скопируйте secrets.example/ в secrets/ и впишите свою сеть; ключ создаётся сам при первой сборке (tools/gen_secrets.py). Открытая копия обновляется python tools/publish.py — одним коммитом, с проверкой на утечки (имя и пароль сети, ключ, адреса).
